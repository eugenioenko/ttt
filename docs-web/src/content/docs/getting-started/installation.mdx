## Quick Install

<Tabs>
  <TabItem label="macOS">
    ```sh
    brew tap eugenioenko/ttt
    brew trust eugenioenko/ttt
    brew install ttt
    ```
  </TabItem>
  <TabItem label="Windows">
    Available in the [Scoop](https://scoop.sh) Main bucket:

    ```sh
    scoop install ttt
    ```

    For a native Windows ARM64 binary, download `ttt-windows-arm64.exe` from [Releases](https://github.com/eugenioenko/ttt/releases) and add it to your `PATH`.
  </TabItem>
  <TabItem label="Linux">
    Download the latest release binary for your platform:

    ```sh
    curl -sSfL https://raw.githubusercontent.com/eugenioenko/ttt/main/install.sh | sh
    ```

    This installs to `~/.local/bin`. To install to a different directory:

    ```sh
    curl -sSfL https://raw.githubusercontent.com/eugenioenko/ttt/main/install.sh | INSTALL_DIR="$HOME/bin" sh
    ```

    Set `INSTALL_DIR` on `sh` so the installer receives it.
  </TabItem>
  <TabItem label="Android (Termux)">
    On arm64 Android devices, run this inside Termux:

    ```sh
    pkg install curl
    curl -sSfL https://raw.githubusercontent.com/eugenioenko/ttt/main/install.sh | sh
    ```

    The installer selects `ttt-android-arm64` and installs it to `$PREFIX/bin`. Set `INSTALL_DIR` on `sh` to choose another directory.
  </TabItem>
  <TabItem label="Arch Linux (AUR)">
    Available on the [AUR](https://aur.archlinux.org/packages/ttt):

    ```sh
    yay -S ttt
    ```
  </TabItem>
  <TabItem label="NixOS">
    :::note
    The flake tracks `main`. A future tagged release will ship a pinned flake; until then, install from `main`.
    :::

    Try it without installing:

    ```sh
    nix run github:eugenioenko/ttt
    ```

    Add to your `flake.nix` inputs:

    ```nix
    {
      inputs.ttt.url = "github:eugenioenko/ttt";
    }
    ```

    Then add `inputs.ttt.packages.${system}.default` to your `environment.systemPackages` or home-manager packages.
  </TabItem>
</Tabs>

## Download Binary

Pre-built binaries for Linux, macOS, FreeBSD, Android (arm64), and Windows (amd64 and arm64) are available on the [Releases](https://github.com/eugenioenko/ttt/releases) page. Download the one for your platform, make it executable, and put it in your `PATH`.

## Go Install

Requires [Go](https://go.dev/) 1.24 or newer:

```sh
go install github.com/eugenioenko/ttt/cmd/ttt@latest
```

This installs the `ttt` binary to your `$GOPATH/bin` (or `$HOME/go/bin` by default). Make sure that directory is in your `PATH`.

## From Source

:::note
Building from source compiles the latest development code, which may include work-in-progress features and could be less stable than official releases.
:::

```sh
git clone https://github.com/eugenioenko/ttt.git
cd ttt
make build
```

This produces an optimized binary at `bin/ttt`. Copy it somewhere in your `PATH`:

```sh
cp bin/ttt ~/.local/bin/
```

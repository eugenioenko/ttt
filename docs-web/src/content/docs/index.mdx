## Features

<CardGrid stagger>
  <Card title="GUI in Your Terminal" icon="laptop">
    Menus, dialogs, mouse support, right-click context menus, and a file explorer. TTT is designed to feel like a desktop app, not a terminal one.
  </Card>
  <Card title="Built-in Themes" icon="star">
    Ships with themes out of the box. Customize everything via JSON or the built-in theme picker with live preview.
  </Card>
  <Card title="LSP Intelligence" icon="setting">
    Completions, diagnostics with inline squiggles, hover info, rename, references, and formatting for 23+ languages.
  </Card>
  <Card title="macOS Command Key" icon="laptop">
    Enable Command (⌘) shortcuts in TTT to save with ⌘S, copy with ⌘C, and paste with ⌘V.<sup>*</sup>

    <small>\* Depends on [terminal support](/guides/macos-command-key/).</small>
  </Card>
  <Card title="Syntax Highlighting" icon="document">
    TTT ships with TextMate grammars for 120+ languages. Highlighting works as soon as you open a file.
  </Card>
  <Card title='<img class="terminal-card-icon" src="/favicon.svg" alt="" /> Integrated Terminal'>
    Run tests or start a dev server in a terminal tab beside your code. Ctrl+click a file path in the output to jump straight to the source.
  </Card>
  <Card title="Git and Jujutsu Built In" icon="github">
    Stage, commit, push, view diffs and blame, and review GitHub PRs directly from the terminal.
  </Card>
  <Card title="Multi-Cursor Editing" icon="pencil">
    Edit several places at once. By default, Ctrl+D adds the next match and Ctrl+K L selects all matches. Both shortcuts can be changed in your keybindings.
  </Card>
  <Card title="Workspace Search" icon="magnifier">
    Search across project folders with ripgrep. Include or exclude files with glob patterns, then open a match at its line.
  </Card>
  <Card title="Workspaces" icon="open-book">
    Multi-folder projects, file explorer, quick open, and tabs. Save and restore workspace layouts with .ttt files.
  </Card>
  <Card title="Zero Config" icon="rocket">
    Single binary, works out of the box. Customize keybindings, settings, and themes only when you want to.
  </Card>
</CardGrid>
